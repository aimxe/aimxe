# Download Lockbreak Island

- [Download the complete ZIP](https://github.com/aimxe/aimxe/raw/refs/heads/main/downloads/Lockbreak-Island-Rebuilt.zip)
- [Download the Roblox Studio place](https://github.com/aimxe/aimxe/raw/refs/heads/main/downloads/Lockbreak-Island-Rebuilt.rbxlx)

On a Mac, open **Finder → Downloads**. Double-click the ZIP to extract it. In Roblox Studio, choose **File → Open from File**, select `Lockbreak-Island-Rebuilt.rbxlx`, and press **Play**. Rojo is not required.

Studio starts with temporary practice progress. The game still needs Studio playtesting; optional Robux purchases require your own product IDs. See the [project README](../README.md) for setup and the [validation report](../VALIDATION.md) for completed checks.
